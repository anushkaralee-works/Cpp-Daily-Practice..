## 🧭 How to Use This Repository

The repository is designed to be followed **from beginner level onward**, while also allowing visitors to directly access individual topics.

### 🆕 Starting C++

Start with the **Basics** section and work through the topics in order.

### 🔎 Already know the basics?

You can directly open the topic you want to practice:

**Loops → Functions → Arrays → Strings → OOP → STL → DSA**

### ✏️ Want to practice a problem?

1. Open the relevant topic folder.
2. Select a problem.
3. Read the problem statement.
4. Try solving it yourself first.
5. Run and test your solution.
6. Compare your approach with the corresponding solution.

### 💡 Only looking for a solution?

You can directly open the relevant `.cpp` file inside the topic folder.
